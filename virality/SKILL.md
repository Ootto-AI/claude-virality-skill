# Virality

This skill ran the Instagram page @jayantcreates.ai: 262 posts, 3,503,488 views, 124,163 comments.
It was not built from theory.
It was built from what actually happened, flops included.

- June to August: 132 posts. Only 3 crossed 10,000 views. Median: about 1,600 views.
- September to October: 130 posts. 31 crossed 10,000 views. 9 crossed 100,000. October median: 6,026 views.

Same account, same topic, same tools.
What changed is everything in this file.

## Rule 1: The hook is the whole game

Most viewers decide in the first 3 seconds.
If nothing happens in those 3 seconds, nothing else you made matters.

**In the first 3 seconds, something extraordinary has to happen on screen.**
Not a title card.
Not a logo.
Not "Hi guys, today I want to talk about".
An event the eye cannot ignore:

- Something blows up (a TNT block next to the old way, an invoice exploding into pieces).
- Something burns (the headline set on fire and burning away).
- Something builds itself (a character raining down out of the sky and landing in frame).
- Something collapses (a wall of failures crumbling, the winners left standing).
- A number climbs fast and locks (a view counter racing to the real total).

Checklist for every hook:

1. **Frame 0 is already moving.** No fade-in. No black frame. The first frame is the most important frame in the video.
2. **The biggest element owns at least 40% of the frame** and is moving from frame 1.
3. **Order is motion, then lock, then claim.** Let the event run about 1 second, land it, then say the claim. The claim lands around 1.2 to 1.6 seconds, never at 0, never after 3.
4. **The first spoken word is within 0.5 seconds,** and it is the subject, not filler. "Business owners:" beats "So today".
5. **It works on mute.** Most people watch without sound. The on-screen event and text must carry the hook alone.
6. **The hook names a pain or a result the viewer feels,** not a feature. "Stop paying an agency $3,000 a month" beats "A new AI tool for Instagram".
7. **No hard cut in the first 3 to 5 seconds.** One continuous build.

If the hook does not pass all seven, rewrite it before writing anything else.

## Rule 2: Talk about their thing, not your tool

Our posts that were about the viewer's own Instagram had a median of 3,543 views.
Posts that were generic tool tips had a median of 2,234.
Our 9 biggest posts of the last two months (100K+ each) were almost all about the viewer's own Instagram and content, not about the tool.

- Bad: "7 Claude tricks that feel illegal to know" (335 views).
- Good: "Editing a video? Just tell Claude" (306,575 views).
- Good: "Claude can now make your Instagram reels" (346,327 views).

The viewer is the main character.
The tool is the vehicle.

## Rule 3: Every line is shown, never just said

- The visual changes on every spoken line.
- Each sentence gets its own mechanism on screen: a screen that types, a counter that climbs, a phone that receives a message, a character that walks to the next station.
- Nothing on screen is ever static. If two frames a second apart look the same, add motion.
- Text appears word by word, in sync with the voice, so it reads on mute.
- Show real proof: real screens, real numbers, real results. A fake number gets caught and kills trust.

## Rule 4: Give them a reason to comment

Posts that asked for a comment keyword had a median of 4,480 views, against 2,444 for posts that did not.
That is how this page got 124,163 comments.

- End with one keyword: "Comment SETUP and I'll send you the setup."
- The keyword must deliver something real in the DM. If you promise it, send it.
- The link goes in the DM, never in a public comment.
- Keep the reel short and put the depth in the caption. The reel opens the loop. The caption and the DM close it.

## Rule 5: Rotate the angle

The same hook framing twice in a row fatigues fast.
Rotate between:

- **Result first:** open on the outcome, then show how.
- **Self-proving:** "Nobody filmed this video. It's me, Claude." The post proves the claim by existing.
- **Contrarian:** "Stop paying an agency for Instagram."
- **Pain first:** "Business owners: you're losing leads in your DMs every night."

## How to use this skill

When the user asks for a reel, a hook, or a script:

1. Ask who it is for and what they should feel or get. One sentence.
2. Write **three** hooks. Each must pass the 7-point checklist in Rule 1. For each, describe the extraordinary on-screen event in the first 3 seconds, second by second.
3. Pick the strongest and say why.
4. Write the script line by line. Next to every line, write what happens on screen. No line without a visual.
5. Write the comment keyword and the real thing the DM delivers.
6. Write the caption: problem, solution, the steps, then the keyword.

When the user asks why a post flopped:

1. Watch or read the first 3 seconds only. Did something extraordinary happen? Usually the answer is no, and that is the whole diagnosis.
2. Check Rule 2: was it about them or about the tool?
3. Check Rule 3: was any line just said and not shown?
4. Check Rule 4: was there a reason to comment, with a real deliverable?
5. Give the one change that would have mattered most, then a rewritten hook.

## Output format for a reel plan

```
WHO IT'S FOR: ...
HOOK (0-3s):
  0.0s  [what is on screen, already moving]
  0.5s  [first spoken word] ...
  1.2s  [the event lands] + [the claim]
  3.0s  [transition into the body]
SCRIPT:
  line 1 -> on screen: ...
  line 2 -> on screen: ...
  ...
CTA: Comment <KEYWORD> -> DM delivers: ...
CAPTION: ...
```
