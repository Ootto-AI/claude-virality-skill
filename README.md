The Claude skill that ran the Instagram page [@jayantcreates.ai](https://www.instagram.com/jayantcreates.ai/).

We did not get there in a straight line.

- **June to August:** 132 posts. Only **3** crossed 10,000 views.
- **September to October:** 130 posts. **31** crossed 10,000 views, and **9** crossed 100,000.

The difference was a handful of patterns.
The biggest one: the first 3 seconds.
Something extraordinary has to happen on screen, or nothing else you made gets seen.
Everything we learned is in [`virality/SKILL.md`](virality/SKILL.md).

## Install

**Claude (claude.ai or the desktop app):**

1. Download this repo as a ZIP (green "Code" button, then "Download ZIP").
2. Zip just the `virality` folder.
3. In Claude, open Settings, then Capabilities, then Skills, and upload the zip.

**Claude Code:**

```bash
git clone https://github.com/Ootto-AI/claude-virality-skill
cp -r claude-virality-skill/virality ~/.claude/skills/
```

## Use it

Just ask:

- "Write me 3 hooks for a reel about my bakery's custom cakes."
- "Plan a reel that gets business owners to comment."
- "Why did this reel flop?" (paste the script or the first 3 seconds)

Claude will write hooks that pass a 7-point checklist, a line-by-line script where every line has a visual, a comment keyword, and a caption.

## Want Claude to post them too?

Connect your Instagram to Claude with [Ootto](https://ootto.ai): in Claude, go to Settings, Connectors, Add custom connector, and paste `https://mcp.ootto.ai/mcp`.
Then Claude can research your niche, make the reels, post them, and reply to comments.
